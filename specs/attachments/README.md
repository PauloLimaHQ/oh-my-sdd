# attachments/

Raw input kept for **provenance** — the third tier of the contract: neither
numbered nor dated, and owed nothing.

Drop here the material that fed a research doc or a spec: a pasted email, a
vendor PDF, meeting notes, an exported thread, a prompt that was executed.
Files keep whatever name they arrived with. Nothing in here is indexed,
validated, or maintained — if a claim in an attachment matters, it gets
promoted into a dated research doc (and from there into a numbered spec),
and the attachment stays behind as the receipt.

The pipeline runs one way:

```
attachments/  →  research/<slug>-YYYY-MM-DD.md  →  specs/NNNN-<slug>.md
     raw               frozen snapshot                 maintained
```
